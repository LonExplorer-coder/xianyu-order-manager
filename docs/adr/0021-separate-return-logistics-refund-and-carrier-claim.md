# 分别推进退货物流、买家退款与承运索赔

退货退款中的物流登记错误、真实物流异常、买家退款和承运方索赔是四类不同事实。用户确认承运方或运单号登记错误后，系统以不可变更正事件保存前后值和原因，当前投影统一使用更正后的信息；关联同一退货包裹的收到与检查事实继续有效，只有改关联订单、售后商品或数量时才要求重新确认。相同运单号默认阻止重复建包，确属合装退货时在同一退货包裹下按商品和数量关联多条退货记录。

真实承运异常使用独立物流事件：没有揽收证据不能认定丢件，承运方确认遗失后才能记录丢件，签收争议与收到后的少件、空包、错货或损坏分别由物流异常和退货检查差异表达。计划退回、实际收到和检查通过数量分别保存；系统不得因签收、丢件或数量差异自动确认退款或责任。

买家退款与承运索赔分别推进。索赔未结束时允许基于人工责任判断先确认退款并记录原因；买家侧处理结束后售后处理单可以结案，未完成的承运索赔继续作为独立待办。索赔成功后新增赔付资金记录，失败则保留失败原因，任何结果都不反向覆盖已经发生的买家退款。
