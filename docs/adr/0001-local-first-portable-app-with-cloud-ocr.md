# 本机优先的免安装应用配合云端 OCR

系统以 macOS 和 Windows 免安装便携版运行，订单数据库、来源截图、备份和配置数据默认保存在用户选择的本机数据目录中，不提供云端实时同步。为获得复杂中文订单截图的识别质量，仅识别阶段通过可替换的 OCR 适配层把图片发送到用户自己的阿里云百炼 qwen3.5-ocr 服务；网络不可用时任务留在本机排队。这个取舍保留了本机数据控制和跨平台便携性，同时接受识别图片会离开本机并产生调用费用。

API Key 等鉴权密钥不得进入订单数据库、所选数据目录、日志、错误、备份、导出文件或代码仓库；密钥由 macOS 钥匙串或 Windows 凭据管理器保存。Workspace ID 与地域不属于密钥，其存储边界以 ADR 0004 的后续细化为准。

## 硬约束

### LF-01 订单业务数据保持本机
- 适用范围：订单数据库、来源截图、备份、配置数据
- 要求：订单业务数据默认保存在用户选择的本机数据目录中，不提供云端实时同步。
- 术语：local-first、本机数据目录、订单业务数据

### LF-02 鉴权密钥隔离
- 适用范围：API Key、访问密钥、鉴权秘密值
- 禁止行为：鉴权密钥不得进入订单数据库、所选数据目录、日志、错误、备份、导出文件或代码仓库。
- 术语：API Key、credential、secret、系统凭据库

## 明确允许

### LF-A01 OCR 阶段上传截图
- 行为：仅在 OCR 识别阶段，通过可替换适配层把待识别图片发送到用户自己配置的云端 OCR 服务。

### LF-A02 保存非密钥连接设置
- 行为：Workspace ID 与地域可以按 ADR 0004 写入 Electron `userData`，但不得因此放宽 LF-02 对鉴权密钥的限制。

### LF-A03 便携程序生命周期操作
- 行为：创建、替换、验证或清理便携程序目录本身是允许的；只要没有改变 LF-01 与 LF-02 的数据和密钥边界，就不构成 local-first 架构变更。

## 需要重新决策的变更

### LF-R01 引入订单数据云同步
- 条件：订单数据库、备份、配置数据或非 OCR 阶段截图将被上传、托管或跨设备实时同步。

### LF-R02 扩大截图外发范围
- 条件：截图将发送给用户配置的 OCR 服务之外的系统，或在 OCR 识别阶段之外离开本机。

### LF-R03 改变密钥存储边界
- 条件：鉴权密钥将离开原生系统凭据库，或进入 LF-02 明确禁止的任一存储、日志、错误、备份、导出或仓库载体。
