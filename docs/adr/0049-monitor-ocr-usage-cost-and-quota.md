# 监控 OCR 用量、费用与额度

OCR 与候选裁决都是按调用计费的外部服务，用户需要了解本月实际发生多少次付费识别尝试、成功率与估算费用，并在超出月度额度前获得提醒或强制停止。同一台电脑、同一应用配置下的所有实际付费调用（主识别、针对性复核、手动与自动重试、连接测试、候选裁决）统一记录到应用配置目录中不可变的全局 `ocr_usage_events` 事实表，共同消耗一个月度额度，并按调用发生的本地自然月聚合统计。

## 估算费用口径

费用是估算而非账单：每次成功调用（HTTP 2xx，无论本地解析是否成功）按设置中的「单次估算单价」计入费用并冻结在事件上，失败调用（网络错误或 HTTP 非 2xx）只计数不计费。单价变更不影响历史事件。连接测试按同单价估算，候选裁决不单独设价。

## 额度与暂停口径

默认仅提醒；硬暂停必须由用户主动开启。硬暂停模式在全局累计估算费用达到月度额度后，于下一个独立付费操作前暂停。所有独立付费操作经同一串行闸门进入，因此背景识别、百炼连接测试和候选裁决连接测试不能并发越过最后一个额度位置。待处理截图仍留在本机识别队列不被删除，暂停月份记入全局设置（`pausedMonth`）。单次识别作为一个独立付费操作，内部的针对性复核与候选裁决不再单独过闸，可完成并记录本次操作的全部实际调用。确认继续或调整额度后，当前数据目录中被硬暂停拦截的队列项立即重新入队，其他数据目录中的队列项在下次打开该目录时重新入队。

恢复有两条路径：调整额度（额度变更在全局设置持久化成功后才复位暂停与放行标记，若仍超限则下次调用重新暂停），或「确认继续」（在全局设置持久化成功后记入 `resumedMonth`，该月内不再自动暂停；跨月后若全局累计仍超限则重新暂停）。写入失败不得改变内存中的额度或放行状态。暂停状态按月自然滚动，无需定时器。月度额度为 0 表示不设额度（不提醒、不暂停）；用量事件写入仍为旁路监控，单条事件写入失败不影响已发生的识别主流程。

## 统计归属

用量事件写入应用配置目录中的全局 `ocr_usage_events` 表，额度与暂停设置保存在全局配置 `ocr-usage-settings.json` 中。所有数据目录的付费调用在本机共同累计，切换数据目录不重置本月用量。正常业务运行由 Electron 单实例锁保证同一应用配置只有一个业务进程，第二次启动只恢复并聚焦现有窗口；便携验收与系统凭据冒烟进程不执行 OCR，不参与此锁。每条事件保存由数据目录绝对路径计算的不可逆指纹，用于保持在途调用的来源归属，不保存原路径。设置页「最近调用记录」展示全局最近 50 条调用、不限定月份（每条带完整日期时间），与「本月统计」卡片的口径相互独立。旧工作区中已有的不可变用量事件在该数据目录首次打开时幂等导入全局事实表；导入失败时拒绝打开该数据目录，防止历史费用缺失时继续付费。导入成功后只从全局表读写。

## 数据与隐私

`ocr_usage_events` 只记录调用元数据（类型、结果、服务商、模型、请求编号、估算费用与不可逆来源数据目录指纹），不保存数据目录路径、截图、OCR 原文或 API Key；与既有 `recognition_attempts` 审计表互补。事件表不可变。
