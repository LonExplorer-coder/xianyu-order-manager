# 监控 OCR 用量、费用与额度

OCR 与候选裁决都是按调用计费的外部服务，用户需要了解本月实际发生多少次付费识别尝试、成功率与估算费用，并在超出预算前获得提醒或强制停止。所有实际付费调用（主识别、针对性复核、手动与自动重试、连接测试、候选裁决）统一记录到不可变的 `ocr_usage_events` 事实表，按调用发生的本地自然月聚合统计。

## 估算费用口径

费用是估算而非账单：每次成功调用（HTTP 2xx，无论本地解析是否成功）按设置中的「单次估算单价」计入费用并冻结在事件上，失败调用（网络错误或 HTTP 非 2xx）只计数不计费。单价变更不影响历史事件。连接测试按同单价估算，候选裁决不单独设价。

## 额度与暂停口径

默认仅提醒；硬暂停必须由用户主动开启。硬暂停模式在累计估算费用达到月度额度后，于下一次付费调用前暂停（识别经 `submitRecognitionSource` 前置闸门、百炼连接测试与候选裁决连接测试经各自设置服务前置闸门），待处理截图仍留在本机识别队列不被删除，暂停月份记入设置（`pausedMonth`）。识别流程内的候选裁决不设独立闸门，随主识别闸门整体拦截（单次识别请求内多笔付费调用最多超出额度一笔请求的量级）。确认继续或调整额度后，被硬暂停拦截的队列项自动重新入队。

恢复有两条路径：调整额度（额度变更即复位暂停与放行标记，若仍超限则下次调用重新暂停），或「确认继续」（记入 `resumedMonth`，该月内不再自动暂停；跨月后若累计仍超限则重新暂停）。暂停状态按月自然滚动，无需定时器。月度额度为 0 表示不设额度（不提醒、不暂停）；用量记录是旁路监控，写入失败不影响识别主流程。

## 统计归属

用量事件写入当前数据目录工作区的 `ocr_usage_events` 表，额度设置是全局配置（`ocr-usage-settings.json`）；切换数据目录后用量按新工作区重新累计，同一全局额度对每个工作区分别生效。设置页「最近调用记录」展示最近 50 条调用、不限定月份（每条带完整日期时间），与「本月统计」卡片的口径相互独立。

## 数据与隐私

`ocr_usage_events` 只记录调用元数据（类型、结果、服务商、模型、请求编号、估算费用），不保存截图、OCR 原文或 API Key；与既有 `recognition_attempts` 审计表互补。事件表不可变，测试降级时若存在事件则拒绝，防止静默丢失用量记录。
