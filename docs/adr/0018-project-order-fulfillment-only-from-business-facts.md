# 订单履约只由业务事实形成投影

原始订单履约状态改为只读投影：尚无本机发货事实时可以采用已确认来源中的基础状态，存在有效发货记录后只按订单商品数量、有效包裹和包裹物流计算。用户不能再直接把订单改成已发货、已收货或已退货，也不能用订单级承运方和运单号代替真实发货；从订单发起的操作必须建立或更新对应发货记录、包裹物流或售后处理事实，事实更正后系统重新投影订单。

`returned`（已退货）不再属于整单履约状态。部分退货、仅退款、换货、拦截退回和补发都按具体商品与数量进入售后处理，并与出库履约、包裹物流、未来库存及财务事实分别呈现。该决策以事实一致性取代人工终态优先，替代 ADR 0009 和 ADR 0017 中的订单级手工物流联动与人工履约终态覆盖。
