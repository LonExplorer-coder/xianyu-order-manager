# 用三种独立模板导出当前合并发货组

合并发货需要同时回答订单、订单商品明细和发货前分组三种不同问题，不能把三种数据压进同一行，也不能让一套模板跨数据粒度解释字段。系统因此把合并发货导出固定为同一个 Excel 工作簿中的“订单总表”、“订单商品明细表”和“合并发货表”，三张表分别使用原始订单、订单商品明细和合并发货组粒度的模板。

合并发货表一组一行，读取当前开放发货组的最终收货信息、成员订单、商品汇总、数量、金额、订单数和组级自定义字段。组级字段按发货组标识独立保存，并可参与对应模板的显示、筛选和排序；模板只保存字段、表头、顺序和查询，不保存一次性的导出脱敏选择。导出预览与最终工作簿共用同一列投影和单元格转换规则。

合并发货表是发货前动态投影，不是发货组档案或发货记录。导出时必须重新核对所选发货组及成员订单仍存在；跨收货信息的组如果尚未明确最终收件人，或者缺少必填组级字段，整个导出被阻止。三张表在同一次导出中使用同一种临时脱敏选择，避免完整隐私数据残留在其他工作表、隐藏列或批注中。

这一选择保留了三种数据粒度各自清晰的行身份，同时让用户能用同一个文件完成订单核对、商品级处理和合并拣货。发货后发生的物流、售后与补发继续由发货记录和相应事实管理，不回写合并发货表。
