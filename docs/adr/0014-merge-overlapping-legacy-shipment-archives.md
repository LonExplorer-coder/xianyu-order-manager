# 归并与旧版档案成员重叠的普通发货档案

旧版零散发货记录缺少档案身份，但同一原始订单同时出现在多个自动回填档案中，会让相同商品剩余数量进入多个操作入口。升级时把成员原始订单有交集、且至少包含一个旧版历史档案的普通履约档案归并为一个档案，包含升级后已经承接该订单继续发货的新档案，并保留全部发货记录和包裹。归并后的建档商品总量按唯一的订单商品计算，同一订单商品出现在多个档案时只计一次，不把各档案的总件数直接相加。单个旧版档案如果只记了某订单的部分发出数量，也要按该成员订单的完整商品数量恢复剩余清单，后续从同一档案继续发货，不再新建重叠的普通履约档案。归并时保留最后一个普通履约档案已确认的最终收货信息；旧档案中的记录仍作为历史证据保留。仅有手机号或地址相同不构成归并证据，以免把不同发货轮次误合并，售后补发也不经此规则归并。
