# 独立模型只裁决有限候选

OCR 继续只生成识别原文，本机规则继续承担六区划分和确定性字段恢复；只有规则能够枚举至少两个带原文位置的有限候选却无法唯一判断时，才可选调用独立的 OpenAI 兼容文本模型。模型一次处理同一截图的全部歧义，只能返回已有候选标识或无法确定；程序拒绝自由字段值、未知标识和不完整响应，并仅按本机预先绑定的结果更新订单，因此模型无法把提示词回显或幻觉文字写入业务数据。

候选裁决默认关闭，内置 DeepSeek、阿里云百炼和自定义 OpenAI 兼容配置，使用与 OCR 分离的系统凭据。验证模型不接收截图，只接收有界的 OCR 区域文字、坐标和候选；失败或无法确定时保留规则结果并进入人工确认，不重试 OCR。每次调用和逐项结果形成不可变裁决记录，以便后续解释当时为何采用或拒绝某个候选；记录只保存严格验证后的结构化字段和本地生成的调用编号，不持久化服务商原始响应或远程不透明请求标识。
