# 可读订单编号与收件人注册表

系统订单编号保持唯一、永久、入库即分配，继续作为身份与对账依据（ADR 0019 不变）。在此之外新增**可读订单编号**：一个非唯一的展示编号，用于肉眼辨识订单所属的计划批次或买家。计划订单编号为「计划创建年月 + 计划当月批次 - 收件人编号 - PL」（如 260802-001-PL），现货订单为「订单入库年月 + 收件人当月订单次序 - 收件人编号 - PT」（如 260805-001-PT）。可读编号是实时投影，归属变化即时反映；订单随发货进入发货快照时冻结当时显示值，面单与历史凭证以快照为准。

**收件人**是姓名加规范化手机号的管理视角身份，收货地址是收件人的属性而非身份的一部分；它与发货匹配键（手机号 + 地址）刻意不同——匹配键是保守的发货规则，收件人是人的管理视角。收件人注册表自动生长：订单入库或人工修改使新的姓名手机号组合首次出现时自动建档发号。收件人编号、计划批次号（含已关闭计划）、现货单当月次序（含已取消订单）都只增发、不回收、不复用。

收件人合并是修正归类错误的唯一入口：合并时编号存续方与显示名称存续方分开选择，地址取并集，必须填写非空原因并留下合并记录；不开放独立的改名或改手机号。合并后实时投影归入存续方，已冻结的快照编号不受影响。
