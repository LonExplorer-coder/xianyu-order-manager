# 以标准商品和商品映射双表交换商品目录

#21 的商品目录工作簿固定使用“标准商品”和“商品映射”两张表，以 SKU 作为关联键。标准商品每个 SKU 一行；商品映射每条当前有效映射一行，并保留原始标题、原始规格、适用范围、平台和卖家账号。这样既能明确发现标准商品表中的重复 SKU，也不会把一个 SKU 的多条、不同适用范围映射压进不可校验的单元格文本；已停用映射和历史事件不属于当前目录交换范围，仍只在本机留痕中保存。

导入采用“选择工作表与列映射 → 预览候选新增、更新、重复和错误行 → 明确解决重复 SKU → 确认有效行”的顺序。确认前不写入；确认时若标准商品或商品映射已偏离用户看到的预览，必须拒绝该次确认并要求重新预览。错误行不阻止其他有效行预览与确认；商品映射的适用范围必须明确提供，不从空值推断更宽范围；导出的列名可被再次自动映射，从而保证同一工作簿可重新导入并保持标准商品与当前有效商品映射语义。

工作簿把现有标题别名改指向另一标准商品时，预览将其列为商品映射候选更新；确认前必须填写非空变更原因，并复用商品映射更正事件保留历史，不直接覆盖而不留痕。工作簿在完整读入和 Excel 解析前检查文件大小、内部文件数量及解压后内容上限，避免异常文件占用无界资源。
