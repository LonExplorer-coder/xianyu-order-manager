# 把售后补发建模为新发货记录和不可变处理轮次

换货和直接补发都是新的实物发出事实。系统为每轮补发建立新发货记录和包裹，并通过售后处理轮次关联来源发货记录、问题商品与数量、退货包裹和补发记录。原发货记录始终保持不变，售后补发不消耗原始订单的普通剩余待发数量。

补发商品再次出现问题时，未完成售后在同一处理单中新建下一轮，并以前一轮补发记录为新来源；已完成售后之后才发生的独立问题则新建售后处理单，不复活旧单。处理轮次、轮次商品、退货关联和补发关联都是不可变事实；当前待办与累计发出、退回、买家持有数量从这些事实投影得出。

该决策保留了后续库存模块把每次补发解释为独立出库、财务模块把每次补发运费解释为独立成本的稳定关联。本阶段不自动生成库存或资金事实，也不扩展为丢件、拦截等上层流程。
