# 释放订单归因来源计划并终身排他

履约计划是发货前的闸门与需求聚合器，不是发货侧的上层控制器。订单释放后与现货单完全等同，按原有动态成组规则参与合并发货——同一买家的计划单与现货单可以合并包裹，时效冲突由释放时点解决（未释放订单对发货组不可见），不由计划命名空间隔离解决。

计划的归纳价值通过归因实现，且归因只跟随释放：**释放**表示订单从计划毕业，其后续发货记录可按「来源计划」归纳，计划工作台据此提供只读履约进展视图与按计划筛选；**退出**表示订单中途离开，不产生任何归因，只在计划档案中保留加入与退出的事实痕迹。归因从释放成员资格与发货事实中派生，不把计划标识复制进订单当前值或发货快照。

为保证归因一对一，一笔订单最多被一个计划释放过；带有释放记录的订单终身不能再加入任何履约计划。加入校验在「无有效归属」之外同时拒绝「曾被释放」的订单。过早释放的补救不借道加入新计划；如未来出现真实场景，以增加显式的撤销释放操作（带原因、清除归因、记录事件）解决。
