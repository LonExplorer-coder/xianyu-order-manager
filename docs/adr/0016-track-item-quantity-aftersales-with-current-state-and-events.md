# 用商品数量当前值与不可变事件管理售后处理单

售后问题属于指定发货记录中的具体发货快照商品和数量，不属于整笔订单、包裹物流状态或发货组档案。每张售后处理单保存当前状态、问题原因、涉及商品数量和修订号；建立以及之后每次状态、原因或数量变化都追加不可变处理事件，记录变更前后完整快照、非空变更原因和时间。

同一发货快照商品可以有多个售后处理单，但所有未完成处理单占用的数量之和不能超过该商品的已发数量。处理单进入已完成后释放这部分售后可处理数量；买家以后提出新的独立问题时另建处理单，不能重新打开已完成历史。这个规则只防止并行售后静默超量，不推断退货入库、买家持有数量或实际退款。

物流和售后继续分别保存：物流变化不推进售后，售后变化不改写物流。包裹一旦存在售后处理证据，就不能再作为“尚未实际交寄”的误操作包裹撤销；后续运输、退货、退款和补发分别由后续业务事实承接。

本任务只建立通用售后骨架。仅退款、退货退款、换货、补发、库存和资金记录仍由后续任务实现，不能通过售后状态提前伪造这些事实。
