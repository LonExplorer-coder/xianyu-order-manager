# 依据有效发货与包裹事实投影订单履约状态

原始订单履约状态是面向订单查询和操作的当前投影，不是发货记录、包裹物流或售后状态的替代品。存在有效发货记录后，系统按订单每条商品的订购数量与有效实际发出数量计算：没有实际发出为待发货，部分商品发出为部分发货，全部商品发出为已发货；只有全部商品已发出且承载这些商品的全部有效包裹均为已签收，订单才自动成为已收货。撤销包裹、作废记录或更正物流状态后，系统按剩余有效事实重新计算。

每次自动变化都以“发货同步”来源追加不可变订单修改记录，保存履约状态修改前后值，不伪装成人工修改。系统自动计算的已收货可以随包裹物流更正回退；用户也可以把相同的已收货值显式确认为人工终态，此时追加一次履约确认记录。人工确认的已收货和已退货优先于较低的自动结果。平台交易状态继续独立保存，取消或退款不会静默改写履约状态。

包裹物流、订单手工物流和售后处理仍各自拥有事实与时间线。原始订单详情、列表和导出通过订单运营投影读取关联事实，不把包裹承运方、运单号或售后状态复制到订单当前值，从而避免多个包裹、部分商品和多个售后处理单被一个可变字段覆盖。
