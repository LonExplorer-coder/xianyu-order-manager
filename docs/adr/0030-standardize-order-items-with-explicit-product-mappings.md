# 以显式商品映射标准化订单商品并保留截图原文

订单截图中的商品标题和规格是来源证据，标准商品则是用户维护的内部业务身份。系统把两者分开保存：订单商品明细始终保留截图原始标题和原始规格，并可另外关联一个由 SKU、标准商品名和标准规格组成的标准商品。修改标准商品名称会更新当前展示，但不会改写任何订单原文。

只有两种情况可以自动产生商品标准化关联：订单原文经过统一文字规范化后与唯一标准商品的名称、规格完全一致，或者已有一条由用户确认的商品映射。相似文字只生成商品标准化候选；候选未经选择不能关联商品，也不能建立映射。相同原文被多次人工关联到同一标准商品后，系统可以提示用户建立映射，但仍须由用户明确确认。

人工选择标准商品和“记住这组订单原文”是两个独立决定。前者只更新本次订单商品明细的关联，后者才影响后续订单；已有历史订单不会因为新建或调整映射而批量重写。订单再次校对时，既有商品标准化关联默认保留，只有本次明确选择时才改变。整个判断和候选过程只读取本机标准商品、商品映射和已确认订单，不向 OCR 服务或其他模型提交训练数据。

订单总表的动态商品列优先显示标准商品名和标准规格，没有关联时回退到截图原文。订单商品明细表同时提供原始标题、原始规格、SKU、标准商品名和标准规格，使来源核对与标准化统计保持清晰边界。
