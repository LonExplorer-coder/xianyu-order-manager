# 按订单商品数量连接发货组、发货记录与包裹

开放的合并发货组管理仍待发出的订单商品数量，一组可以分多次实际发出并产生多条发货记录；待发数量归零后才关闭。每条发货记录代表一次真实发货，可以包含一个或多个包裹；每个包裹通过包裹商品明细精确关联原始订单中的商品和实际发出数量，因此一个包裹可以混装多笔订单，同一订单商品也可以拆入不同包裹或不同发货记录。

从第一次实际发出起，同一轮的开放组和后续多条发货记录由唯一发货组档案持续组织；档案身份和界面阶段见 [ADR 0012](0012-preserve-shipment-group-archives-across-records.md)。

这一选择比“一个发货组固定生成一条记录”或“包裹只关联整笔订单”更复杂，但只有数量级分配才能同时表达整单发货、部分发货、多包裹、丢件、拦截、退货、补发以及未来库存和财务变化。售后补发始终生成新的发货记录，但不消耗原始订单的剩余待发数量。

错误发货记录只有在所有相关包裹均未实际交寄时才可带原因作废，记录本身和作废原因继续保留，仍具发货资格的数量返回开放发货组。部分包裹已经交寄时不得作废整条记录，只能撤销未交寄包裹并对已交寄包裹发起拦截；承运方或运单号错误属于留痕更正，不抹掉真实发货事实。作废也不能删除已经确认的库存或资金事实，相关事实需要分别保留或冲正。

本决策在发货记录能力交付后，取代 ADR 0009 中仅凭非空运单号判定真实发货、清空运单号即可退回待发货的部分规则；在此之前，ADR 0009 继续描述当前订单级基础联动。
