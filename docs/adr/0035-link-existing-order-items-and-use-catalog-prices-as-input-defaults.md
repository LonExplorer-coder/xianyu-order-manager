# 显式关联已有订单商品并把目录价格限定为录入默认值

标准商品是工作区内共用的规范商品身份，订单商品标准化关联是某条订单商品当前确认的身份，商品映射则是以后遇到相同原文时采用的匹配规则。三者必须分开保存和操作。普通订单详情与订单商品明细提供单笔和批量关联入口；修改商品映射默认只影响未来，历史订单只有经过独立预览和确认才能批量重新关联。

商品映射具有当前平台与卖家账号、当前平台全部账号、整个工作区三级适用范围，默认采用当前平台与卖家账号。匹配时优先使用更精确范围。同一范围内同一组规范化原始标题和规格只能有一个当前有效目标；单笔订单可以例外关联其他标准商品而不改变映射。

任何生命周期阶段都允许带原因更正订单商品的标准商品关联。更正只改变商品身份归属，不修改来源标题、来源规格、数量、发货、退货、退款、补发或索赔事实。未来库存或财务事实已经存在时，通过独立 SKU 归类更正调整归属，不能静默重写原流水。

标准商品可以保存一个可选的当前默认订单单价，并保留不可变价格变更历史。该值只用于人工录入预填，不是实际成交金额、采购成本或平台结算价格。选择标准商品时的名称、规格和价格同步是一次性带入，之后标准商品修改不能自动改写订单。

已有 OCR 或历史订单关联标准商品时不覆盖来源原文，且默认不覆盖订单单价；人工新增订单商品可以默认带入标准名称、标准规格和默认订单单价。关联时默认启用“优先展示标准商品信息”，但原始字段和标准字段始终可以分别查看和导出。单价变化自动重算商品小计，商品总价只在用户确认后更新，成交金额和运费永远不自动修改。
