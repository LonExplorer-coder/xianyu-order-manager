# 在表格模板中持久保存字段级脱敏规则

订单核对、发货和对外统计需要展示不同范围的个人信息，单次全局脱敏开关不能表达三种数据粒度中各工作表的用途。每套表格模板因此分别保存买家昵称、收件人、手机号和收货地址的受控显示方式；每个字段只能选择完整显示或系统定义的对应脱敏规则，新建模板及未选择用户模板时默认使用安全规则，不能配置任意脚本或正则。

模板脱敏规则只作用于导出投影，不改写订单当前值、发货组或应用界面。导出预览与最终工作簿必须共用同一单元格转换结果，并从实际工作表投影生成脱敏摘要；完整原文不得作为隐藏列、批注、元数据或额外工作表写入文件。该决策取代 ADR 0029 中“三张表共用一次性脱敏选择”和“模板不保存脱敏选择”的部分，保留三种数据粒度独立模板、成员一致性检查和发货组导出边界。
