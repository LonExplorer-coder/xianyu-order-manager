# 落定成本与利润视图的计算口径

#75 要求依据已确认的资金记录与采购事实提供利润视图。ADR 0042 已定「订单为主维度、商品汇总下钻、发货记录与售后单只作来源」；本决策落定视图内部的计算规则。全部为只读计算，不新增表、不改写任何事实（#75 验收第 6 条）。

## 决策

1. **已实现利润（订单）= 平台结算净额 + 承运理赔净额 − 退款净额 − 平台服务费净额 − 运费净额（首发/退货/补发/拦截）− 其他人工费用净额 − 采购成本**。符号约定：各类型净额按「收入为正、支出为负」带符号记账（如退款列显示 −12.00），因此公式字面的减法等价于把各列带符号净额直接相加后再减采购成本。各类型按收入−支出净额列示；`order_transaction`（成交金额）只作参照列示，不参与利润——成交 ≠ 结算 ≠ 利润（规格 11）。成交金额列取订单本身的 `amount_cents`，不依赖资金记录。
2. **采购成本 = 订单累计净发出数量 × 商品加权平均采购单价**。加权平均单价 =（Σ到货数量×到货采购单价 − Σ关联采购单的供应方退货数量×该采购单单价）÷（Σ到货数量 − 关联采购单退货数量），分母非正时回退 Σ金额÷Σ数量，仍非正则为 0。成本唯一来源是采购订单确认的单价（ADR 0042 决策 3）；采购付款与供应方退款是资金事实，不参与订单成本，列示于「采购与其他」区。
3. **订单累计净发出 = Σ发货明细数量 − Σ退回冲回数量**。发货明细排除已撤销包裹（`shipment_package_cancellation_events`，整单作废即全部包裹撤销）；补发记录的明细挂原订单，重复补发自然累计。退回冲回 = 退货检查转可销售的数量 + 退回报废的数量（两种结果商品都实际回来了）；检查为瑕疵或其他时不冲回（保守口径，等待供应方退货或后续处理），供应方退款以采购资金列示，不反向改写订单成本。
4. **报废损失是独立结果行，不属于任何订单**：到货检查报废（按到货批次单价）+ 检查结果为报废的库存流水（退货检查报废与人工库存检查报废，按加权平均单价）。退回报废同时冲回订单发出成本并计入报废损失，一笔成本只计一次损失。商品毛利 = 分摊净额 − 净发出成本 − 报废损失。
5. **多订单挂账的资金记录按订单内商品明细小计金额占比分摊**（合并发货的首发运费、跨订单售后单的退款/运费/赔付），余数分给排序最前（订单号）的订单。商品维度的分摊同理：订单参与净额按明细小计占比分摊到商品，未映射明细的份额进「未映射」行，不丢失也不冒充。Σ订单利润 − Σ报废损失 = Σ商品毛利（映射部分）。
6. **待确认资金事项经同一归属链挂到订单，单列「待确认净额」与明细，绝不进入已实现利润**（#75 验收第 3 条）。采购付款、供应方退款与无来源直接录入不进订单利润，在「采购与其他」区单独列示并可下钻。

## 追溯口径（#75 验收第 4、5 条）

- 部分退款：售后单逐笔退款记录（事实级锚点）→ 售后单明细 → 商品与数量。
- 重复补发：每条发货/补发记录的发出明细（记录号、承运单号、商品、数量、单价）。
- 退货检查：退货明细的检查结果（收到数量 × 结果）逐条列示。
- 报废成本：到货检查报废行与库存检查报废流水，商品、数量、单价俱全。

## 影响

- `src/main/profit-service.ts` 只读计算，`queryProfitReport` 一次返回订单行、商品行、未映射、采购与其他与总览；不落任何中间表，加权平均单价按查询时点计算（口径在 UI 标注）。
- 后续若引入批次成本核算（FIFO/批次台账），推翻本决策第 2、3 条，版本化迁移。
