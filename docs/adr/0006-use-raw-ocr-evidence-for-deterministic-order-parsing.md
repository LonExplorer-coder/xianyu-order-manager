# 使用识别原文确定性拆分订单

百炼 `key_information_extraction` 会把完整地址与省、市、区县作为可独立生成的字段。实际订单曾出现完整地址正确包含“锦江区”，独立区县却生成“江城区”的自相矛盾结果；提示词、低随机采样和物理裁剪只能降低概率，不能把生成式字段结构变成事实约束。相同问题也可能表现为字段说明回显、推广内容混入或两个业务字段互相对调。

生产订单识别因此只调用一次 qwen3.5-ocr `advanced_recognition`，保存识别原文（含文字、坐标及原始响应），并在本机划分平台状态、收货信息、商品、金额、订单详情和履约操作六区。字段值由本机规则从相应区域的识别原文确定性恢复；广告和推荐区域由坐标布局隔离。省、市、区县只从完整收货地址拆分，模型响应中的独立行政区字段不得进入业务结果。收货区或底部履约区出现“去发货”时判为待发货，页头明确显示卖家已发货或等待买家收货时判为已发货；已付款订单缺少唯一履约依据时建立待确认项。布局或其他关键字段无法可靠确定时同样保留识别原文并建立待确认项，不再回退到整图或裁剪图的结构化 KIE。

该流程把每张截图的正常付费调用从两次减少为一次，并关闭二次生成字段污染订单的入口。它不声称识别原文本身永远正确，也不声称当前正则已覆盖全国全部行政区划；省略层级、同名地区、省直管县级市或功能区等无法可靠判断的情况应留空并人工确认。若后续需要提高行政区划完整率，应引入带版本的本机行政区划数据和父子层级校验，而不是重新让 OCR 模型猜测。

未来可以在规则无法解决的语义歧义上接入独立模型，但该模型只能从识别原文候选中选择并返回可定位依据，不得自由生成字段。历史批次已有的识别冲突和多次识别原文继续保持可读，不因新流程而迁移或重写。
