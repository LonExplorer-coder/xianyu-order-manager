# 用包裹当前值与不可变事件管理物流进展

物流进展属于包裹，不属于整笔订单或发货组档案。每个有效包裹保存一个可筛选的物流状态当前值，并在每次人工更新时追加一条不可变物流时间线事件，记录状态修改前后值、原因和时间；承运方与运单号更正继续写入同一条包裹物流时间线。发货记录只汇总所属有效包裹的当前状态和待办，不把多包裹压成单一结论，也不改写发货快照、订单履约状态或售后状态。

确认实际发出表示货物已经离开卖方控制，因此新包裹默认进入运输中；升级前已经存在的真实发货包裹也归为运输中。待承运方接收仍可由用户显式登记，用于实际交寄已确认、但承运方尚未产生接收结果的场景。已撤销包裹不参与发货记录物流汇总或筛选。
