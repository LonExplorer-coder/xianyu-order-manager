# Domain Docs

本仓库采用单上下文领域文档布局。

## 开始工作前

- 读取仓库根目录的 `CONTEXT.md`（如果存在）。
- 读取 `docs/adr/` 中与当前工作相关的架构决策记录。
- 若文件尚不存在，继续工作即可，不要将缺失本身视为错误。

## 术语规则

规格、Issue、测试名称和实现讨论必须使用 `CONTEXT.md` 中定义的领域术语，避免为同一概念随意创造同义词。

若需要的概念尚未定义，应先判断它是错误用词还是领域词汇缺口。若方案与既有 ADR 冲突，必须明确指出冲突，而不是静默覆盖既有决策。
