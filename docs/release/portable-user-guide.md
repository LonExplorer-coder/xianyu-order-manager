# 免安装版使用说明

闲鱼订单管理提供两个免安装压缩包：

- macOS（Apple 芯片）：`XianyuOrderManager-darwin-arm64-<版本>.zip`
- Windows 10/11（64 位）：`XianyuOrderManager-win32-x64-<版本>.zip`

应用不需要 Node.js、开发工具、命令行或管理员权限。请只使用可信来源提供的完整 ZIP，并核对同时提供的 SHA-256 文件。

## 第一次打开

### macOS

1. 双击 ZIP 完成解压。
2. 把 `XianyuOrderManager.app` 放到当前用户可写的位置，例如个人目录中的“应用程序”文件夹或自己常用的文件夹；不必放入系统级 `/Applications`。
3. 双击应用打开。
4. 若系统第一次提示无法确认开发者，可在 Finder 中按住 Control 点击应用，选择“打开”，再确认一次。不要关闭系统安全保护。

当前阶段允许出现一次系统安全提示；正式签名和公证的发行包通常不会出现这一步。

### Windows

1. 右键 ZIP，选择“全部解压”。不要直接在压缩包预览中运行程序。
2. 保留解压后的完整文件夹，不要只移动其中的 EXE。
3. 双击 `XianyuOrderManager.exe`。
4. 若 SmartScreen 第一次提示，请先确认文件来源和 SHA-256 一致，再选择“更多信息 → 仍要运行”。应用不应请求管理员权限。

## 选择订单数据目录

首次启动会要求选择一个独立的数据目录，默认建议位置是“文档/闲鱼订单数据”。这里保存订单数据库、识别队列、来源截图和后续备份。

不要把数据目录放在应用或 Windows 解压程序文件夹里面。应用会阻止这种选择，以免升级或删除程序时连同订单数据一起删除。

应用正常运行后，可在“设置 → 数据存储位置”查看完整路径并选择“更改数据目录”。可以连接一套已有订单数据，也可以选择空目录建立一套新数据；选择器会从当前目录打开。切换成功后工作区会重新加载，之后启动也会记住新目录。

切换数据目录不会复制、合并、移动或删除原目录内容。若目的是把同一套数据迁移到其他磁盘，请先完全退出应用，备份并复制整个数据目录，再启动应用并从设置页连接复制后的目录；确认订单和来源截图完整前不要删除旧目录。

百炼 API Key 不在数据目录中，而是保存在当前系统用户的 macOS 钥匙串或 Windows 凭据管理器中。把订单数据复制到另一台电脑后，需要在新电脑重新填写 API Key。

## 升级或移动程序

1. 先完全退出闲鱼订单管理。
2. 备份独立的订单数据目录。
3. 删除或移走旧应用/旧程序文件夹。
4. 解压新版本并启动。

只要没有移动或删除独立数据目录，新版本会从系统启动配置中重新打开原目录；订单和来源截图不会随程序替换而消失。如果原数据目录不存在或暂时无法访问，应用会明确报错，不会静默创建一个看起来像“数据丢失”的空订单库。

## 卸载

删除应用或 Windows 程序文件夹只会移除程序本身，不会删除独立订单数据目录。确认不再需要订单、来源截图和备份后，再单独处理数据目录。
