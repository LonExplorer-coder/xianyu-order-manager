## 自动化门槛

- [ ] ZIP 能完整解压，包含可执行程序、`app.asar` 和对应平台的系统凭据原生模块。
- [ ] 从解压后的程序执行系统凭据写入、读回、删除及删除后复查。
- [ ] 程序 A 首次启动后选择独立数据目录，导入一笔合成订单及其来源截图并完全退出。
- [ ] 删除程序 A 的整个目录后，独立启动配置、订单数据库和来源截图仍存在。
- [ ] 从程序 B 再次启动，自动打开原数据目录并读回同一笔订单、商品和来源截图。
- [ ] 自动化证据中的 `gitDirty` 为 `false`，版本、提交和 ZIP SHA-256 与本表一致。

## macOS 人工验收

- [ ] Finder 双击 ZIP 并打开应用，不需要安装 Node.js、开发工具或使用终端。
- [ ] 普通用户可以启动；若出现首次安全提示，可通过系统提供的“打开”流程继续，不关闭系统安全保护。
- [ ] 原生目录选择器默认指向“文档/闲鱼订单数据”，选择后能进入订单工作台。
- [ ] 上传一张私有验收截图并完成入库，退出应用后重新打开，订单和来源图仍可查看。
- [ ] 删除或替换应用后再次打开，原订单数据仍在。

- [ ] 在标准用户账号中“全部解压”ZIP，双击 EXE 启动，不需要命令行或管理员权限。

- [ ] 原生目录选择器默认指向“文档/闲鱼订单数据”，选择后能进入订单工作台。
