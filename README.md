# 闲鱼订单管理系统

一个面向个人卖家的本机订单管理工具：批量识别包含闲鱼订单详情的来源截图，将结果校对后汇总为可自定义表头的订单表、商品明细表和合并发货表。

当前状态：已进入第一阶段实施。首个纵向切片提供数据目录选择、单张来源截图上传、可控识别结果校对、原始订单持久化和重启读取；真实阿里云 OCR 尚未接入。

## 当前可运行能力

- 首次启动选择独立数据目录，之后自动打开最近目录。
- 空数据状态突出上传一张完整订单详情截图。
- 使用不联网、不计费的可控识别器生成订单草稿。
- 对照来源截图校对订单和商品明细后确认入库。
- 订单、商品明细、来源截图及不可变来源快照保存在本机。
- 关闭并重开后继续查看原始订单；同一数据目录只允许一个写实例。

## 本地开发

需要 Node.js 24.18.x 和 pnpm 10。项目根目录的 `.node-version` 已固定当前验证版本。

```bash
pnpm install
pnpm start
```

常用验证命令：

```bash
pnpm check
pnpm package
```

Electron 只通过受限 preload 接口向界面开放目录选择与订单操作。结构化数据使用 Node 内置 SQLite，来源截图保存在所选数据目录的 `screenshots` 子目录；程序目录可以独立替换。

## 隐私说明

当前可控识别器不会联网。真实来源截图、API Key、本机数据库和备份不得提交到代码仓库；自动化测试只使用程序生成的脱敏合成图片与固定识别结果。
