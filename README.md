# 闲鱼订单管理系统

一个面向个人卖家的本机订单管理工具：批量识别闲鱼订单详情截图，将结果校对后汇总为可自定义表头的订单表、商品明细表和合并发货表。

当前状态：需求规格阶段，尚未开始业务代码开发。
