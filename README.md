# 闲鱼订单管理系统

一个面向个人卖家的本机订单管理工具：批量识别包含闲鱼订单详情的来源截图，将结果校对后汇总为可自定义表头的订单表、商品明细表和合并发货表。

当前状态：已进入第一阶段实施。应用已打通“单张闲鱼订单截图 → 百炼真实识别 → 人工校对 → 原始订单入库 → 重启读取”的纵向流程。批量上传、自动入库、重复订单处理、合并发货、自定义表格和导出仍按后续 Issue 实施。

## 当前可运行能力

- 首次启动选择独立数据目录，之后自动打开最近目录。
- 空数据状态突出上传一张完整订单详情截图。
- 把来源截图以 Base64 Data URL 直接发送到用户自己的中国北京百炼 `qwen3.5-ocr`，不依赖公共图床。
- 每张截图通常调用 1 次 OCR；关键字段缺失或冲突时最多自动定向复核 1 次，可能产生第 2 次调用与费用。复核失败时仍保留首次结果供人工校对。
- 识别订单号、支付宝交易号、买家与收货信息、地址、下单/付款时间、商品总价、运费、成交金额及一个或多个商品明细；通过页面位置约束区分买家昵称和收件人，并在模型漏拆时从完整地址补拆省、市、区县。
- OCR 未识别到的金额保留为空白并阻止确认；用户明确填写 `0.00` 才按零元保存。
- 识别 `×N`、`xN`、`数量 N`、`共 N 件` 等明确数量；截图未显示数量时默认记为 1，并在校对页直观提示“截图未显示数量，已按 1 件处理”。
- 对照来源截图校对规范化结果后确认入库；OCR 原始响应、规范化结果和最终值分开保留。
- 可取消本次校对：不会生成订单，且该草稿之后不能误入库；来源截图与识别证据仍保留以便追溯和后续容量清理。
- 订单、商品明细、来源截图及不可变来源快照保存在本机。
- 关闭并重开后继续查看原始订单；同一数据目录只允许一个写实例。
- 在设置页配置中国北京地域的百炼 `qwen3.5-ocr`，API Key 只保存到 macOS 钥匙串或 Windows 凭据管理器。
- 手动测试 OCR 连接；必须在费用提示中再次确认，默认测试和 CI 不发起付费调用。

## 本地开发

需要 Node.js 24.18.x 和 pnpm 10。项目根目录的 `.node-version` 已固定当前验证版本。

```bash
pnpm install
pnpm start
```

常用验证命令：

```bash
pnpm check
pnpm package
```

macOS 普通本地打包会对整个应用执行临时签名，因此钥匙串功能可用；这个包仅适合本机或内部验证。正式对外分发使用 Apple Developer Program 的 `Developer ID Application` 证书，并把公证凭据保存在 macOS 钥匙串，而不是项目文件中：

```bash
xcrun notarytool store-credentials xianyu-order-manager-notary \
  --apple-id "你的 Apple ID" \
  --team-id "你的 Team ID"
pnpm make:mac:release
pnpm verify:mac:release
```

`notarytool` 会安全提示输入 Apple ID 的 App 专用密码。正式构建会自动启用 Hardened Runtime、Developer ID 签名和 Apple 公证；验证命令会检查签名、公证票据及 Gatekeeper。若要使用其他钥匙串配置名称，可通过 `XIANYU_NOTARY_KEYCHAIN_PROFILE` 指定。

Electron 只通过受限 preload 接口向界面开放目录选择、订单操作和不可读取原文的 OCR 凭据操作。结构化数据使用 Node 内置 SQLite，来源截图保存在所选数据目录的 `screenshots` 子目录；程序目录可以独立替换。

如需人工验证自己的百炼配置，请在“设置 → 百炼 OCR”中保存 Workspace ID 和 API Key，再点击“测试连接”。第二次确认后，应用会把一张程序内置的合成图片直接发送到百炼，这可能产生一次 OCR 调用；订单截图不会参与该连接测试。之后每张订单截图通常产生 1 次真实 OCR 调用；关键字段缺失或冲突时最多自动定向复核 1 次，因此可能产生第 2 次调用与费用。即使复核失败，首次识别结果仍会保留供人工校对。

真实识别验收建议使用一张尚未入库、包含完整订单详情的截图：上传后先核对订单号、交易号、买家昵称与收件人是否分离、手机号、省市区、三种金额、多商品条目数、明确数量和时间，再修改任一字段并确认入库；关闭并重开应用后，订单详情应继续显示最终值和来源截图。取消流程可另上传一张合成或废弃截图验证：点击“取消本次校对”后应回到订单页，且不会新增订单。

## 隐私说明

上传订单截图后，图片会发送到用户所配置的阿里云百炼服务进行识别；关键字段缺失或冲突时，同一张图片最多再发送 1 次用于自动定向复核。单张原文件上限为 7.5 MB，网络请求禁止自动重定向。原图、结构化订单和不可修改的识别证据同时保存在用户选择的本机数据目录。API Key 仅由系统凭据库保存，不进入订单数据库、日志、识别证据、备份或导出；若上游异常回显实际密钥，应用会拒绝保存该响应。真实来源截图、API Key、本机数据库和备份不得提交到代码仓库；自动化测试只使用程序生成的脱敏合成图片与固定服务端响应，不发起付费调用。
